# Organizador-de-Declara-o-de-Imposto-de-Renda
Organizador de Declaração de Imposto de Renda é um modelo em Excel criado para facilitar o preenchimento e organização dos dados necessários na declaração anual. Ele reúne informações pessoais, informes de rendimento bancários e registros de holerites em um só lugar, tornando o processo mais simples e estruturado.
