# Organizador de Declaração de Imposto de Renda

Este repositório contém um modelo em Excel para organizar dados necessários na declaração de imposto de renda, incluindo informações pessoais, informes de rendimento bancários e notas de holerites.

## 📂 Estrutura do Projeto
- **Organizador_de_Declaracao_de_Imposto_de_Renda.xlsx**  
  Planilha principal para preenchimento dos dados.
- **/images**  
  Pasta opcional com capturas de tela ilustrando o uso da planilha.

## 🧾 Seções da Planilha
1. **Dados do Titular**  
   Informações pessoais como nome, CPF, endereço, telefone e e-mail.

2. **Informes de Rendimento Bancários**  
   Registro dos valores atuais em diferentes bancos.  
   Exemplo:  
   - Banco do Brasil → R$ 50  
   - XP Investimentos → R$ 500.000  
   - Banco Western Union → R$ 500.000  
   - BTG Pactual → R$ 500.000  

3. **Notas Bancárias ou Extrato de Holerites**  
   Entradas mensais de receita.  
   Exemplo:  
   - 10/03/2026 → Holerites → R$ 3.000  

## 🚀 Como Usar
1. Baixe o arquivo `.xlsx`.
2. Preencha seus dados pessoais e financeiros.
3. Utilize a aba de notas para registrar entradas mensais.
4. Opcionalmente, adicione comprovantes em PDF como anexos.
